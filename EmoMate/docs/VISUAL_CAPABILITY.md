## 📋 概述

EmoMate的AI伴侣具备**视觉能力**，可以通过摄像头看到用户所处的真实环境，理解场景内容，并在对话中自然地提及环境信息。

### 核心能力

- 🎬 **场景理解**: 识别用户所在位置（咖啡馆、办公室、卧室等）
- 📦 **物品识别**: 检测场景中的物品（笔记本电脑、咖啡杯、书籍等）
- 🎨 **氛围感知**: 理解场景氛围（安静学习、工作专注、休闲放松等）
- 💡 **光线分析**: 感知光线条件（室内灯光、自然光、昏暗等）
- 📚 **细节识别**: 识别书名、产品品牌、文字内容等详细信息
- 🔄 **智能触发**: 场景变化、定时检测、对话关键词三种触发方式
- 💾 **场景记忆**: 缓存场景信息，避免重复分析
- 💬 **对话融合**: 场景信息自然融入AI对话

## ⚡ 智能触发机制

### 1. 场景变化触发

**工作原理**: 每30秒自动拍照，检测场景相似度

```typescript
// 触发条件
if (相似度 < 70%) {
  触发深度分析;
  重置定时器;
}
```

**典型场景**:
- 用户从室内走到室外
- 从办公室移动到咖啡馆
- 从卧室走到客厅

**防止误触发**: 1分钟冷却时间

### 2. 定时触发

**工作原理**: 每5分钟自动触发一次深度分析

```typescript
// 时间线
每30秒拍照 (不分析)
  ↓
5分钟后触发分析
  ↓
更新场景缓存
```

**使用场景**:
- 长时间停留在同一地点
- 保持场景信息新鲜度
- 检测场景中的细微变化

### 3. 对话关键词触发

**工作原理**: 检测用户消息中的视觉关键词

**关键词列表** (12个):
```typescript
[
  "这是什么", "看看", "识别", "分析",
  "周围有什么", "什么环境", "看见",
  "这本书", "拍照", "这个东西",
  "我在哪", "现在什么"
]
```

**触发特点**:
- 立即触发（< 1秒）
- 高优先级（绕过冷却时间）
- 精确匹配（避免"看起来"等误触发）

**示例对话**:
```
用户: "这本书你知道吗？" [拿着书对镜头]
    ↓
检测关键词: "这本书"
    ↓
立即拍照分析
    ↓
识别: 《人类简史》by 尤瓦尔·赫拉利
    ↓
AI: "当然知道！《人类简史》是尤瓦尔·赫拉利的经典作品..."
```

## 💾 场景缓存与去重

### 缓存机制

**存储方式**: MMKV (比AsyncStorage快10-30倍)

**缓存策略**:
- 最多保存3个场景
- 每个场景保留30分钟
- 自动清理过期场景

**数据结构**:
```typescript
interface CachedScene {
  timestamp: number;           // 时间戳
  imageBase64: string;         // 图像数据
  sceneData: SceneData;        // 场景信息
  triggerReason: string;       // 触发原因
}
```

### 智能去重

**目的**: 相同场景不重复调用API，节省成本

**工作流程**:
```typescript
新场景拍摄
  ↓
与缓存场景对比
  ↓
if (相似度 > 95%) {
  复用缓存场景;  // 节省API调用
  更新时间戳;    // 保持活跃
} else {
  调用Claude Vision分析;
  保存新场景;
}
```

**节省效果**:
- 典型场景: 节省60-80%的API调用
- 成本统计: 实时显示节省的调用次数和成本

## 💰 成本管理

### API定价

- **模型**: Claude 3.5 Sonnet (`claude-sonnet-4-5-20250929`)
- **输入**: $3/M tokens
- **输出**: $15/M tokens
- **单次成本**: $0.004 - $0.01

### 成本优化策略

| 策略 | 说明 | 节省 |
|------|------|------|
| **智能去重** | 相似场景复用缓存 | 60-80% |
| **图片压缩** | 压缩到500KB以下 | 20-30% |
| **定时采样** | 5分钟间隔而非实时 | 90%+ |
| **后台暂停** | App后台时停止检测 | 避免浪费 |

### 预估成本

| 使用强度 | 每日API调用 | 每日成本 |
|---------|-----------|---------|
| **轻度** | 5-10次 | $0.02-0.05 |
| **中度** | 10-20次 | $0.05-0.10 |
| **重度** | 20-40次 | $0.10-0.20 |

**实际节省**: 通过智能去重，通常能节省60-80%的API调用
