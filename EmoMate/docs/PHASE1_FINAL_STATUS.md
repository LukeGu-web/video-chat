## 🔄 Phase 1 调整说明

### 为什么暂时禁用过渡语音播放?

#### 发现的问题
当前实现会导致**两个不连贯的回答**:
```
用户: "你好"
  ↓
立即播放: "好的呢~" (过渡语音)
  ↓
1秒后播放: "你好呀!" (真实回答)
```

**问题**: 像两个人在说话,体验很奇怪!

#### 根本原因
Phase 1 使用的是**完整响应模式**(等待 Claude 完整回答后播放),过渡语音和真实回答是**两个独立的音频**,无法无缝衔接。

#### 正确的解决方案
过渡语音需要在 **Phase 2 流式响应**中才能真正发挥作用:
```
用户: "你好"
  ↓
立即播放: "嗯..." (过渡语音)
  ↓ [并行: Claude 流式生成第一句]
0.5秒后: "嗯...你好呀!" (无缝切换到真实回答)
```

**Phase 2 流式响应**可以在第一句话生成时**停止过渡语音**并**无缝切换**,实现真正的连贯对话。
