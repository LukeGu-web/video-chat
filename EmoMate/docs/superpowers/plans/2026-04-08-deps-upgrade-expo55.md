# EmoMate Dependency Upgrade — Expo SDK 55 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade EmoMate from Expo SDK 54 to SDK 55, and update all safe non-expo packages to their latest compatible versions.

**Architecture:** Two isolated batches — first the Expo ecosystem (all expo-* packages aligned via `expo install --fix`), then safe non-expo packages (minor/patch updates only). Each batch ends with a commit. Packages with major breaking changes (tailwindcss, typescript, immer, react-native-worklets) are explicitly skipped.

**Tech Stack:** Expo SDK 55, React Native (SDK-determined version), npm

---

## Files Modified

- `EmoMate/package.json` — version pins updated by both batches
- `EmoMate/package-lock.json` — regenerated by npm

No source files are expected to change. If `expo install --fix` or the Batch 2 installs produce TypeScript errors, those are surfaced in the verification task and must be fixed before closing this plan.

### Task 2: Batch 1 — Upgrade Expo SDK to v55

**Files:**

- Modify: `EmoMate/package.json` (expo + expo-* versions)
- Modify: `EmoMate/package-lock.json`

- [ ] **Step 1: Install Expo SDK 55**

```bash
cd EmoMate
npx expo install expo@^55
```

Expected: npm installs expo ~55.x.x and updates package.json.

- [ ] **Step 2: Align all expo-* packages to SDK 55**

```bash
npx expo install --fix
```

This command reads the installed expo version and installs the correct peer versions of all expo-* packages, babel-preset-expo, react, and react-native. Expected output lists packages being updated, ending with no errors.

Packages this touches:

- expo-asset, expo-audio, expo-build-properties, expo-constants
- expo-dev-client, expo-file-system, expo-image-manipulator
- expo-speech, expo-speech-recognition (2.x → 3.x), expo-sqlite
- expo-status-bar, babel-preset-expo
- react, react-native (set to SDK 55 target versions)

- [ ] **Step 3: Verify package.json reflects SDK 55 versions**

```bash
grep -E '"expo":|"expo-|"react":|"react-native":' package.json | head -20
```

Expected: all expo-* entries show `~55.x.x`, expo itself shows `~55.x.x`.

- [ ] **Step 4: Commit Batch 1**

```bash
git add package.json package-lock.json
git commit -m "deps: upgrade Expo SDK 54 → 55 (expo install --fix)"
```

**Files:**

- No changes — read-only verification

- [ ] **Step 1: Run TypeScript compiler**

```bash

```

Expected: exits with code 0, no errors printed.

If errors appear: they are likely caused by a changed API in `expo-speech-recognition` (2.x → 3.x), which is the one expo-* package with a major version jump.
