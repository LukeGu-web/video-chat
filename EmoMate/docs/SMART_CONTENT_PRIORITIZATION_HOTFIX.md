# 智能内容优先级系统 - 紧急修复报告

**问题**: AI回复过于简洁,很多时候只有语气词而没有实质内容
**修复日期**: 2025-10-23
**修复类型**: 🔥 Hotfix - 规则增强
**状态**: ✅ 已完成

---

## 🐛 问题描述

### 用户反馈
> "回答是简洁了很多,但是,很多时候就是语气词,根本没有回答我的问题啊!"

### 问题示例
```
用户: "你吃了什么午饭"
AI回答: "嗯…" ❌ (只有语气词,没有实质内容)

用户: "今天天气怎么样"
AI回答: "诶？" ❌ (只有语气词,没有回答问题)

用户: "你在做什么"
AI回答: "让我想想~" ❌ (拖延,没有实质回答)
```

### 根本原因分析
1. **System Prompt规则不够强**: "简短"规则太强,但"必须有实质内容"规则不够明确
2. **语气词使用冲突**: "禁止单独使用语气词"与"简短回复"产生了误解
3. **SmartSentenceBuffer未检测纯语气词**: 没有专门针对纯语气词句子的低评分规则

## 🔧 修复方案

### 修复1: System Prompt强化 (ai.ts)

#### 新增"核心原则"章节
```markdown
### 🚨 核心原则 (必须遵守)
1. **第1句必须有实质内容** - 不能只是"嗯…"、"诶？"等语气词
2. **直接回答核心问题** - 不要拖延、不要铺垫、直接说重点
3. **语气词可以有,但必须紧跟实质内容** - 例如"嗯…今天不错呢~"而不是只说"嗯…"
4. **宁可少说一句,也不要说没用的话** - 质量 > 数量
```

#### 增强"第1句话"规则
**修改前**:
```markdown
### 第1句话 (必须包含 - 核心答案)
- **最重要的信息**: 直接回答用户的核心问题
- **示例**:
  - ✅ "吃了寿司~"
  - ❌ "嗯…让我想想"
```

**修改后**:
```markdown
### 第1句话 (必须包含 - 核心答案) ⚠️ 最重要!
- **强制要求**: 第1句必须直接回答用户的问题,不能只是语气词
- **必须包含实质内容**: 具体的答案、信息、观点或反应
- **正确示例**:
  - ✅ "吃了寿司~" (有实质内容 - 回答了吃什么)
  - ✅ "我很好呢~" (有实质内容 - 回答了状态)
  - ✅ "今天天气不错~" (有实质内容 - 描述天气)
  - ✅ "我在看书呢~" (有实质内容 - 说明在做什么)
- **错误示例** (只有语气词,没有实质内容):
  - ❌ "嗯…" (纯语气词)
  - ❌ "诶？" (纯语气词)
  - ❌ "嗯…让我想想" (只是拖延,没回答问题)
  - ❌ "这个嘛…" (只是拖延,没回答问题)
```

### 修复2: SmartSentenceBuffer算法增强

#### 新增Rule 0: 纯语气词检测 (最高优先级)

**代码位置**: `src/utils/smartSentenceBuffer.ts:241-254`

```typescript
// Rule 0: Pure filler words/interjections (CRITICAL - heavy penalty)
const pureFillerPatterns = [
  /^(嗯|啊|哦|诶|呀|嘛|哈)+[…~。！？]*$/,  // "嗯…", "诶？"
  /^(让我想想|这个嘛|那个)[…~。！？]*$/,    // "让我想想~"
  /^[…~。！？\s]+$/                          // 只有标点
];

if (pureFillerPatterns.some(pattern => pattern.test(sentence.trim()))) {
  return 0.1; // 非常低的分数 (阈值是0.6,会被过滤)
}
```

**效果**:
- "嗯…" → 重要性: 0.1 ❌ 被过滤
- "诶？" → 重要性: 0.1 ❌ 被过滤
- "让我想想~" → 重要性: 0.1 ❌ 被过滤
- "吃了寿司~" → 重要性: 0.7 ✅ 播放

#### 新增内容长度检测

**代码位置**: `src/utils/smartSentenceBuffer.ts:256-263`

```typescript
// Check if sentence is too short (likely just filler)
const contentLength = sentence.replace(/[~。！？…\s]/g, '').length;
if (contentLength < 3) {
  score -= 0.3; // 惩罚过短句子
}
```

**效果**:
- "嗯~" → 实际内容1字符 → 扣0.3分
- "诶？" → 实际内容1字符 → 扣0.3分
- "吃了寿司~" → 实际内容4字符 → 不扣分
