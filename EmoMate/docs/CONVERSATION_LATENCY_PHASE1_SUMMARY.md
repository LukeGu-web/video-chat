     3. 根据情绪选择 → `excited`, `empathy`
     4. 根据内容情感检测

## 🔧 技术实现细节

### 1. Token 优化策略
- **减少Token数量**: 平均减少33%,特殊场景(storytelling)减少20%
- **保持质量**: 通过System Prompt引导保持回答完整性
- **动态调整**: 根据对话类型(simple/normal/detailed/storytelling)智能选择

### 2. 过渡语音系统
- **立即反馈**: 不等待过渡语音播放完成,立即调用Claude API
- **智能选择**: 根据用户消息和情绪智能选择合适的过渡语音
- **轻量级**: 当前使用文本日志占位,待Phase 1测试后生成真实音频文件

### 3. System Prompt 优化
- **明确长度要求**: 每句话10-20字,1-2句话为主
- **避免冗长**: 除非明确要求,否则保持简洁
- **快速响应优先**: 引导AI优先考虑对话流畅度
